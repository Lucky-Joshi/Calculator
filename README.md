# Simple Calculator

A basic calculator built with HTML, CSS, and JavaScript that performs addition, subtraction, multiplication, and division.

## Features

- Clean, responsive UI
- Basic operations: +, -, *, /
- Decimal point support
- Clear button (C)
- Error handling for division by zero and invalid operations

## Files

- index.html - HTML structure
- style.css - Styling and layout
- script.js - Calculator logic

## Usage

Open index.html in your browser and start calculating!

## Example

1 + 2 = 3
5 / 0 = Error
